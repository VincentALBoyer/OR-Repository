# Preemptive Flexible Job Shop Scheduling Problem

**Vincent Boyer, María Angélica Salazar Aguilar.** A fragment-free constraint programming approach with preemptive
edge-finding for the preemptive flexible job shop scheduling problem.

This folder will host the source code, the detailed results per instance and the best schedules found for the paper.
They will be uploaded once the preprint is available on arXiv; the citation and the arXiv link will be added here.
